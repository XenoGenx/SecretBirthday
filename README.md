# สุขสันต์วันเกิด — หน้าเว็บตัวอย่าง

วางไฟล์นี้ไว้ในโฟลเดอร์โปรเจกต์แล้วเปิด `index.html` ในเบราว์เซอร์มือถือหรือเดสก์ท็อป

- ใส่รูปของคุณที่มุมล่างซ้ายเป็น `images/left.png`
- ใส่รูปของคุณที่มุมล่างขวาเป็น `images/right.png`

Unlock / รหัสเข้า:
- หน้าเริ่มต้นจะมีช่องให้พิมพ์รหัสเพื่อเปิดการ์ด ตัวรหัสเริ่มต้นคือ `bestie` (แก้ได้ในไฟล์ `script.js` ตัวแปร `correctCode`).

เพลงพื้นหลัง:
- มีปุ่มเล่น/หยุดเพลงที่มุมบนขวา ใช้ YouTube embed (รหัสวิดีโอ: `M-5UZ_YJjM4`).
- บราวเซอร์มือถือมักจะบล็อกการเล่นอัตโนมัติ ดังนั้นต้องกดปุ่มเพื่อเริ่มเพลงด้วยตัวเอง.

ปรับแต่ง:
- เปลี่ยนข้อความใน `index.html`
- แก้ธีมสีใน `styles.css` (ตัวแปร :root)
- เพิ่ม/ลดอีโมจิใน `script.js` array `emojis`

เปิดหน้าอย่างง่าย (จากโฟลเดอร์นี้):
```bash
# Windows
start index.html

# Mac
open index.html

# หรือเปิดไฟล์โดยตรงในมือถือผ่านเซิร์ฟเวอร์เล็กๆ เช่น Python
python -m http.server 8000
```
